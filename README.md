# RiotAccountsManager By Gabry

---

## 🇮🇹 Italiano

**RiotAccountsManager** è un progetto indipendente nato per risolvere i bug che si verificano quando si passa da un account all'altro sul Riot Client, e per automatizzare completamente il processo di login ai giochi Riot Games (League of Legends, Valorant).

### Funzionalità

- **Gestione account** — Aggiungi, rimuovi e organizza tutti i tuoi account Riot in un unico posto
- **Login automatico** — Seleziona l'account e il gioco: il launcher si apre e le credenziali vengono inserite automaticamente
- **Crittografia locale** — Tutti i dati sono cifrati sul tuo PC, nulla viene inviato online
- **Master password** — Proteggi l'accesso alle credenziali in chiaro con una password personale
- **Export / Import** — Trasferisci i tuoi account su un altro PC tramite file cifrati `.racm`
- **Tray icon** — L'app resta in background nella tray di sistema, sempre a portata di mano
- **Aggiornamenti automatici** — L'app controlla automaticamente la disponibilità di nuove versioni all'avvio
- **Setup wizard** — Configurazione guidata al primo avvio, inclusa la calibrazione adattiva dei campi di login

### Installazione

1. Scarica il file `RiotAccountsManager_Setup.exe` dalla sezione [Releases](../../releases)
2. Avvia il setup e segui la procedura guidata
3. Al primo avvio verrà mostrato il wizard di configurazione

### Note

> Questo è un progetto personale e indipendente, non affiliato a Riot Games.  
> Verranno implementate nuove funzionalità su richiesta e risolti i bug segnalati.  
> Per segnalazioni apri una [Issue](../../issues).

## 🇬🇧 English

**RiotAccountsManager** is an independent project built to eliminate the bugs that occur when switching between accounts on the Riot Client, and to fully automate the login process for Riot Games titles (League of Legends, Valorant).

### Features

- **Account management** — Add, remove and organize all your Riot accounts in one place
- **Automatic login** — Select the account and game: the launcher opens and credentials are entered automatically
- **Local encryption** — All data is encrypted on your PC, nothing is sent online
- **Master password** — Protect access to plaintext credentials with a personal password
- **Export / Import** — Transfer your accounts to another PC via encrypted `.racm` files
- **Tray icon** — The app stays in the background in the system tray, always accessible
- **Automatic updates** — The app automatically checks for new versions on startup
- **Setup wizard** — Guided configuration on first launch, including adaptive login field calibration

### Installation

1. Download `RiotAccountsManager_Setup.exe` from the [Releases](../../releases) section
2. Run the setup and follow the guided procedure
3. On first launch the configuration wizard will appear

### Notes

> This is a personal and independent project, not affiliated with Riot Games.  
> New features will be implemented on request and bugs will be fixed as needed.  
> To report issues, open an [Issue](../../issues).
